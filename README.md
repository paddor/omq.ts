# OMQ.ts has moved

OMQ.ts now lives in the OMQ.rs repository under
[`pure/typescript`](https://github.com/paddor/omq.rs/tree/main/pure/typescript),
next to the Rust transports it talks to. Its history moved along.

This repository is archived. Open issues and pull requests at
[paddor/omq.rs](https://github.com/paddor/omq.rs).

The package keeps its name: `@paddor/omq` on
[npm](https://www.npmjs.com/package/@paddor/omq) and
[JSR](https://jsr.io/@paddor/omq). New releases come from OMQ.rs.
